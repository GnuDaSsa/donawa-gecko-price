# 닷츠·피클 이슈 운영

닷츠와 피클이 제보한 도나와 이슈를 Codex가 찾아 수정하고, 검증 결과와 함께 검토할 PR을 연다. 제품 동작과 데이터 수집에는 [기존 제품 계약](production-mvp.md)을 적용한다.

- 완료 기준은 실제 저장소에서 대기열을 조회할 수 있고, GnuDaSsa 명의의 기존·신규 제보와 제외 조건이 자동 테스트를 통과하며, 후속 실행이 같은 이슈의 PR을 중복 생성하지 않는 것이다.
- 이번 구성의 범위는 제보 양식, 대상 판별, 작업 재개, 검증, PR 인계까지다. 운영 배포와 데이터 변경은 개별 이슈의 승인 범위를 따른다.
- 로컬에서 `npm run issues:next`로 대기열을 조회하고, `npm test`와 `npm run lint`로 검증한다.
